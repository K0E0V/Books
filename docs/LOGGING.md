# Переключение режима логирования (Serilog)

В приложении есть переключатель: писать **весь лог** или **только ошибки**.

Режим задаётся настройкой `Serilog:Mode`:

| Значение | Что пишется |
|---|---|
| `All` (по умолчанию) | Весь лог: Information, Warning, Error, Fatal |
| `ErrorsOnly` | Только ошибки: Error и Fatal |

Логи пишутся в консоль и в файлы `logs/log-.txt` (с ротацией по дням).

## Способ 1. Через файл конфигурации

1. Откройте `appsettings.json` (для продакшена) или `appsettings.Development.json` (для разработки — он имеет приоритет в dev-окружении).
2. Найдите секцию:

   ```json
   "Serilog": {
     "Mode": "All"
   }
   ```

3. Чтобы включить режим «только ошибки», замените значение:

   ```json
   "Serilog": {
     "Mode": "ErrorsOnly"
   }
   ```

4. Сохраните файл и перезапустите приложение. Перекомпиляция НЕ требуется.

Чтобы вернуться к полному логу — верните `"Mode": "All"` и снова перезапустите.

## Способ 2. Через переменную окружения (без правки файлов)

Переменная окружения имеет приоритет над appsettings.json:

```
Serilog__Mode=ErrorsOnly
```

Где задать:

- **Локально (PowerShell):**
  ```powershell
  $env:Serilog__Mode = "ErrorsOnly"
  dotnet run
  ```
- **Локально (cmd):**
  ```bat
  set Serilog__Mode=ErrorsOnly
  dotnet run
  ```
- **Visual Studio:** проект → Свойства → Debug → Environment variables → добавить `Serilog__Mode` = `ErrorsOnly`.
- **IIS:** Configuration Editor → system.applicationHost / environmentVariables (или через `web.config`).
- **Windows-служба / сервер:** переменная окружения уровня системы или сервиса.

## Как проверить, что переключатель работает

1. Включите `ErrorsOnly`, перезапустите приложение.
2. Откройте любую страницу — в консоли и в `logs/log-YYYYMMDD.txt` не должно появляться информационных записей (`[INF]`, `[DBG]`).
3. Вызовите ошибку (например, сохранение формы с некорректными данными, ведущим к исключению) — запись `[ERR]` или `[FTL]` должна появиться в логе.
4. Верните `All` — информационные записи снова появятся.

## Примечание

Настройка `Logging:LogLevel` в appsettings — это отдельный, стандартный логгер .NET.
Данный переключатель управляет именно **Serilog** (консоль + файлы `logs/`).
