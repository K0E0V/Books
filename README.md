5.2	Разработайте простое приложение “Домашняя библиотека”

1.	По каждой книге должно храниться; 
1.1.	Название
1.2.	Автор
1.3.	год издания
1.4.	оглавление в виде xml поля. Оглавление в виде xml файла.
1.5.	Прочие данные, которые Вы посчитаете необходимыми.
2.	Создать хранимые процедуры для  insert, update, delete, select …
3.	Для управления библиотекой реализовать карточку, список, функции редактирования, создания, изменения, просмотра записей с помощью хранимых процедур.
